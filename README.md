### Industrial WeightBridge Management System

A premium, secure, and production-ready Desktop Application designed for automated and manual vehicle weighing operations in factories, mills, and heavy industries. This software accurately tracks, records, and manages multi-stage weight measurements while ensuring strict operational security through dual-role access control. 

### 🚀 Key Features

### ⚖️ Advanced Weighing Operations

* **First Weight Measurement:** Records the initial gross or tare weight of an incoming vehicle (Khali Wazan / Pehla Wazan).
* **Second Weight Measurement:** Automatically fetches the previous record of the registered vehicle and calculates the net weight difference once it returns loaded or empty.
* **Direct Driver Manual Weight:** Allows instant operations when the driver already knows the standard empty vehicle weight, accelerating the overall factory turnaround time.

### 🖨️ Reporting & Utilities

* **Real-time Record Management:** Browse, filter, and track comprehensive historical logs of everyday weighing data.
* **Instant Slip Printing:** High-quality weight slip and token printing for drivers, gatekeepers, and office records.

### 🔒 User Roles & Access Control

The system is equipped with a robust security architecture split into two distinct operational tiers to prevent data tampering: 

### 👤 Admin Account (Standard Operations)

Designed for everyday workplace monitoring with highly focused privileges to keep operations straightforward: 

* Execute first, second, and third manual weighing workflows.
* View and search operational logs and vehicle history records.
* Generate and print official weight slips.

### 🛡️ Operator Account (Full System Control)

An unrestricted super-user dashboard specifically tailored for system management, database maintenance, and error correction: 

* **Full Application Access:** Complete control over all standard features, settings, and hardware integrations.
* **Data Rectification:** Ability to securely edit weight records and details in case of human input errors at the scale.
* **Database Maintenance:** Administrative authority to wipe, archive, or empty the database system during standard cleanups or new shift initiations.

### 🛠️ Technology Stack

* **Language:** C# / .NET
* **UI Framework:** Windows Forms / WPF (Desktop Application)
* **Database:** Secure local / network database storage for industrial environments
